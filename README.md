# Controlab

一个面向本科生与研究生课外理解的在线控制实验室。第一版聚焦传递函数分析：让模型、图像、指标和知识解释使用同一份计算结果。

## 已实现

- 输入任意真有理或正则传递函数
- 阶跃、斜坡、正弦输入的时域响应
- Bode 幅频图与相频图
- 根轨迹与零极点标记
- 奈奎斯特图与 `-1` 点标记
- 相位裕度、增益裕度、极点与稳定性概览
- 与当前模型联动的读图指南和小实验
- SVG 与 2× PNG 高清导出
- 响应式桌面与移动端布局

全部控制计算都在浏览器本地完成，第一版无需账号和后端。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

验证构建与数值测试：

```bash
npm test
```

## 当前边界

- 支持分子阶次不高于分母阶次的模型。
- 根轨迹使用数值多项式求根，适合学习与常规模型探索。
- 稳定裕度通过对数频率采样与插值估计。
- 结果用于学习和理解，不替代安全关键工程验证。

## 技术结构

- Vinext / React / TypeScript
- 无图表库，曲线由原生 SVG 绘制
- 四阶 Runge–Kutta 时域积分
- Durand–Kerner 多项式求根
