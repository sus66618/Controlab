# 矩阵滚动条与重置交互设计

## 目标

让状态空间工作台的横向滚动区域符合现有深色视觉，并让工具栏按钮准确表达其行为。

## 滚动条

- 矩阵编辑区、公式横向区域和分析矩阵统一使用细暗色滚动条。
- 轨道与容器背景融合，滑块默认使用低对比深灰，悬停时适度提亮。
- 保留原生滚动、触控板和键盘行为，不增加自制滚动组件。

## 重置

- 将“新建空白”改名为“重置”。
- 点击后恢复首次进入状态空间页面时的完整状态：默认质量–弹簧–阻尼模型、状态响应页签、分析栏收起、矩阵粘贴面板关闭、粘贴内容与错误提示清空。
- 维度、ABCD 矩阵、初始状态、输入配置、仿真时长和轨迹坐标轴随默认模型一起恢复。

## 验证

- 添加状态重置测试，证明修改后的状态能恢复为初始快照。
- 运行现有测试、代码检查和生产构建，避免影响矩阵计算与仿真。
