# 模块导航与系统辨识重构设计

## 目标

- 模块内顶部导航与首页四大模块保持同名、同序，自动隐藏当前模块。
- 闭环控制开关只属于“系统分析”，不出现在现代控制、系统辨识和动力学仿真中。
- 系统辨识从术语面板改成“数据 → 模型结构 → 验证”的可读实验流程。

## 架构

建立唯一模块目录 `CONTROL_MODULES`，集中保存模块 ID 与中文名称。首页卡片、模块路由和顶部导航都消费该目录；新增模块时，顶部导航无需逐页修改。

系统辨识保留现有 ARX 最小二乘与自由仿真计算，只重构教学呈现：先解释 `t / u / y`，再用中文解释 `na / nb / nk`，最后用测量曲线、模型曲线、拟合度、RMSE 和分行多项式展示验证结果。原始 CSV 收入折叠编辑区，避免默认占满页面。

## 交互规则

- 当前模块不显示在顶部快捷导航中，其余模块按首页顺序排列。
- 点击任一模块按钮直接切换，不经过首页。
- 进入系统分析时闭环默认关闭，用户可在该页开启。
- 系统辨识示例切换后同步更新数据、建议阶次和结果；修改 CSV 或阶次后点击“重新辨识”。
- 公式采用 `A(q^{-1})`、`B(q^{-1})` 与模型关系三行展示，长公式允许横向滚动但不压缩字号。

## 验证

- 单元测试验证任一当前模块都会得到其余模块，且顺序稳定。
- 单元测试验证 ARX 多项式展示的符号、阶次和延迟。
- 运行完整构建、代码检查与现有数学测试，防止控制算法回归。
