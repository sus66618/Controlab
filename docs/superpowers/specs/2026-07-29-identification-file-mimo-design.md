# 系统辨识文件导入与多维扩展设计

## 目标

- 支持直接导入 CSV 与 XLSX 文件，浏览器本地读取，不上传服务器。
- 根据表头自动识别时间、输入和输出通道，并在导入后立即辨识。
- 将 SISO ARX 扩展为支持 MISO、SIMO 与 MIMO 的多变量 ARX（VARX）。
- 保留当前粘贴 CSV 与三个教学示例。

## 数据约定

表格第一行为列名。时间列接受 `t`、`time`、`时间`；输入列接受以 `u`、`input`、`输入` 开头的名称；输出列接受以 `y`、`output`、`输出` 开头的名称。至少需要一个输入和一个输出，所有有效数据行必须为有限数值，时间必须严格递增。

无表头的三列粘贴数据继续按 `t,u,y` 解析；文件导入必须提供表头，以避免把多通道列猜错。CSV 支持标准双引号字段。XLSX 读取第一个包含有效数据的工作表，并在 Web Worker 中解析。文件大小上限 10 MB、采样点上限 50000、输入输出通道合计上限 16，支持 `.csv` 与 `.xlsx`，不支持旧式 `.xls`。

## 数学模型

多变量模型采用

`A(q⁻¹)y(k) = q⁻ⁿᵏ B(q⁻¹)u(k) + e(k)`。

对每个输出方程，用所有输出的历史值和所有输入的历史值构造同一回归向量，再分别做最小二乘。自由仿真时所有预测输出同步递推，因此交叉输出耦合会真实参与结果，而不是拆成互不相关的 SISO 模型。

统一阶次 `na / nb / nk` 作用于全部通道，总回归参数上限 160。最小二乘使用带秩检查的 QR 分解；输入共线或激励不足时明确拒绝输出不可信模型。首版不做每个通道独立阶次、非线性辨识或状态空间子空间辨识。

## 页面

数据区增加文件选择与拖放区域。成功导入后显示文件名、采样点数、输入维度和输出维度；失败时说明缺少哪类列或哪一行无效。

图表区增加输出通道选择器。原始数据页显示全部输入与当前输出，拟合和残差页显示当前输出的测量、预测或残差。模型区在 SISO 时继续显示标量多项式，在多通道时显示矩阵模型关系、A/B 矩阵尺寸，并按滞后阶次展开当前输出对应的系数。

## 依赖与资源

使用 `read-excel-file` 的 Web Worker 入口读取 XLSX；Excel 解析器与主界面分包，选择文件后才在后台线程工作。依赖与 npm 缓存均位于 E 盘项目目录。

## 验证

- 表格识别测试覆盖多输入多输出、中文/英文表头、缺列和非递增时间。
- 数学测试用手工生成的二输入二输出耦合系统验证系数与自由仿真拟合度。
- 运行完整构建、lint 与现有回归测试。
