# 仿真实验大厅封面重设计

## 目标

把实验大厅中五张抽象占位图改为可直接识别实验对象的静态微缩装置图。封面只承担识别与区分作用，动画和复杂交互继续留在实验内部。

## 视觉方案

沿用大厅现有暗色工业风、卡片结构和各实验主题色。缩略图使用轻量 HTML 与 CSS 结构绘制，不增加图片资源、动画或第三方依赖。

- 弹簧—阻尼：固定墙、弹簧、阻尼器、质量块和轨道。
- 直流电机：电机外壳、转子、输出轴和负载轮。
- 无源 RLC：电源与串联 R、L、C 构成的闭合回路。
- 有源 Sallen-Key：两级 RC 网络、三角运放和反馈线路。
- 小车倒立摆：轨道、小车、细摆杆与直立平衡点。

所有图形保持静止，使用统一线宽、圆角、低亮度辅助线和单一实验强调色。即使隐藏文字，用户也应能依据结构区分五种对象。

## 组件结构

新增独立的 `ExperimentCoverVisual` 展示组件，通过实验 ID 选择对应的语义化静态图形。`SimulationGallery` 只负责传入实验 ID，不再渲染三个无意义的通用占位元素。

每种封面图形拥有独立的类名与有限节点，公共容器负责尺寸、背景和颜色。这样新增实验时只需增加一个封面分支，不会污染卡片布局或实验仿真代码。

## 响应式与可访问性

- 图形随卡片宽度缩放，不产生横向滚动。
- 封面属于装饰性内容，保持 `aria-hidden="true"`，实验名称仍由卡片文本提供。
- 不使用动画；系统的减少动态偏好无需额外分支。

## 验证

- 静态契约测试确认五个实验均有专属封面标识，且旧的三个通用占位节点已移除。
- 运行 lint、构建和现有测试套件。
- 在本地浏览器检查五张封面的识别度、对齐、桌面布局与窄屏溢出。

## 非目标

- 不改变实验名称、分类、导航或仿真模型。
- 不为封面增加交互、动画、实时状态或 Canvas。
- 不引入位图、图标库、SVG 文件或新依赖。
