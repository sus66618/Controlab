# 系统辨识方法扩展设计

## 目标

把现有仅支持 VARX 的辨识页扩展为可比较、可调参、可验证的教学工作台。所有曲线、指标和模型系数必须来自页面实际执行的算法；训练集与验证集严格按时间分割，不用验证数据反向拟合参数。

## 范围

第一阶段提供五类方法：

1. **ARX / VARX**：保留最小二乘实现，支持 SISO 与 MIMO。
2. **FIR**：令输出记忆阶次为零，仅估计有限脉冲响应；支持 SISO 与 MIMO。
3. **正则化 ARX**：使用岭回归抑制高阶参数膨胀；支持 SISO 与 MIMO。
4. **ARMAX / VARMAX**：用迭代扩展最小二乘估计噪声多项式；多输出时采用各输出独立的对角噪声模型，并在界面明确说明，不伪装成完整耦合噪声模型。
5. **OE（输出误差）**：直接最小化自由仿真误差。首版仅支持 SISO；MIMO 数据下禁用并说明原因。

N4SID 暂不纳入本阶段。它应与状态维数选择、奇异值图和状态空间矩阵展示组成独立专题，避免只放一个名词按钮。

## 模型与参数

统一配置类型包含方法、阶次和验证参数，但界面只显示当前方法真正使用的字段：

- `na`：输出多项式阶次，ARX、正则化 ARX、ARMAX 使用。
- `nb`：输入多项式或脉冲响应长度，全部方法使用。
- `nk`：输入纯延迟，全部方法使用。
- `nc`：噪声多项式阶次，仅 ARMAX 使用。
- `nf`：OE 分母阶次，仅 OE 使用。
- `lambda`：岭回归强度，仅正则化 ARX 使用，允许 `0` 作为普通 ARX 对照。
- `maxIterations`、`tolerance`：ARMAX 与 OE 的迭代上限和停止阈值。
- `trainRatio`：按时间顺序划分训练集和验证集，默认 70%。
- `preprocess`：不处理、去均值或去线性趋势；变换参数只从训练段计算。
- `includeBias`：是否估计常值偏置项；默认关闭，开启后偏置不参与岭正则化。

阶次控件改为一致的自定义数字输入，不使用浏览器原生上下箭头。普通阶次范围为 0–10；算法根据通道数、样本数和参数上限再次校验，拒绝欠定模型。

## 算法真实性

### FIR 与 ARX

用 QR 最小二乘求解回归矩阵。FIR 是 `na = 0` 的独立教学入口，页面展示脉冲响应系数，不用 ARX 名称包装。

### 正则化 ARX

通过向回归矩阵追加 `sqrt(lambda) * I` 实现岭回归。偏置项不参与正则化；结果展示实际使用的 `lambda`。

### ARMAX

先以 ARX 得到初始残差，再把过去 `nc` 项残差加入回归矩阵，迭代更新参数，直到参数变化小于 `tolerance` 或达到 `maxIterations`。结果必须报告实际迭代次数和是否收敛。MIMO 情况共享输入与输出回归量，每个输出使用自己的残差历史，即对角噪声模型。

### OE

以 ARX/FIR 结果初始化分子和分母参数，使用带阻尼的数值 Gauss–Newton 最小化训练段自由仿真残差。每次候选更新都检查参数有限性与离散分母稳定性；不稳定或损失上升则增大阻尼并拒绝该步。结果报告实际迭代次数、收敛状态和失败原因。

## 预测与验证

页面明确区分两种结果：

- **一步预测**：每一步使用历史实测输出，衡量短期预测能力。
- **自由仿真**：初始化后只使用模型自身的历史输出，衡量模型能否独立复现系统动态。

验证集从训练集结束后的时刻开始。模型只使用训练段估计；验证段允许使用分割点之前的真实历史作为初始化，之后不得把验证输出喂回自由仿真。拟合度沿用 `100 * (1 - ||y-yhat|| / ||y-mean(y)||)`，允许出现负值，不截断、不美化。

去均值、去趋势及数值缩放所需统计量只能由训练段计算，再原样应用到验证段。所有图线和 RMSE 在展示前恢复为原始物理量单位，防止预处理后的漂亮数字冒充真实误差。

每个输出通道分别计算并展示：

- 训练/验证的一步预测拟合度与 RMSE；
- 训练/验证的自由仿真拟合度与 RMSE；
- 基于训练一步预测残差的 AIC、BIC；
- 残差均值及前 20 阶归一化自相关。

## 自动阶次搜索

用户可选择评价准则：验证集自由仿真拟合度、AIC 或 BIC。搜索只遍历当前方法相关阶次，并设置候选数量上限，防止浏览器卡死：

- 默认阶次范围 1–6，`nk` 范围 0–3；
- 最多评估 180 个候选；超出时提示缩小范围；
- 候选必须满足样本数和参数上限；
- OE 不执行全组合搜索，只用 ARX 候选筛出前 5 个初值再做 OE 优化；
- 结果列出前三名及其参数、验证指标，用户确认后才应用，不偷偷改动当前配置。

## 界面结构

现有三步流程保持不变：导入数据、选择模型、验证模型。

“选择模型结构”区域改为：

1. 顶部方法切换：ARX、FIR、正则化、ARMAX、OE；
2. 一行简短说明当前方法适用场景及维度限制；
3. 动态参数网格；
4. “开始辨识”和“自动选择阶次”两个主操作。

验证区域增加“一步预测 / 自由仿真”切换，以及“训练 / 验证”切换。顶部摘要显示方法名、模型维度和当前视图拟合度。详细指标采用紧凑表格，残差自相关作为第四个图表页签；不增加大段教学口号。

当某方法不支持当前数据维度时，按钮保留但禁用，并给出一句具体原因。例如：`OE 首版仅支持单输入单输出数据`。

## 模块边界

- `lib/identification/types.ts`：方法、配置、结果和指标类型。
- `lib/identification/regression.ts`：QR、岭回归及公共回归矩阵工具。
- `lib/identification/predict.ts`：一步预测、自由仿真和指标计算。
- `lib/identification/methods/`：每种辨识方法独立实现。
- `lib/identification/search.ts`：候选生成、限制与排序。
- `lib/systemIdentification.ts`：保留兼容导出，避免现有调用一次性断裂。
- `components/identification/`：拆分方法选择、动态参数、指标与搜索结果组件。

算法层只接收纯数据和配置并返回不可变结果，不读取 UI 状态。界面展示只消费结果对象，避免显示值与真实计算分叉。

## 错误处理与性能

- 对样本不足、回归矩阵秩亏、非有限数值、迭代不收敛和不稳定 OE 模型分别给出明确错误。
- ARMAX/OE 即使达到迭代上限，也只返回带 `converged: false` 的真实结果，不冒充收敛。
- 数据仍限制为 50,000 点；高开销迭代和自动搜索放入 Web Worker，主界面显示进度并允许取消。
- 搜索取消后保留原模型和结果，不产生半成品。

## 测试与验收

采用测试驱动实现，至少覆盖：

- 每种方法在已知但带噪的独立测试数据上恢复合理动态；测试数据与算法系数分文件生成，避免把断言答案复制进输入。
- 训练/验证严格分割，自由仿真过程中不读取验证输出。
- 预处理统计量只来自训练段，并且展示指标恢复到原始量纲。
- 正则化能降低病态高阶模型的参数范数。
- ARMAX 迭代状态、OE 稳定性约束和不收敛状态真实可见。
- 自动搜索不超过候选上限，排序结果可复现。
- SISO/MIMO 能力限制、参数校验及错误文案。
- UI 只显示当前方法相关参数，原生数字微调箭头不会重新出现。
- 项目现有系统分析、现代控制和仿真测试不回归。

使用项目中的 `test/` 保存供用户手动导入的实验样例；自动化测试代码继续放在 `tests/`。
