# 反相 MFB 有源低通重构设计

## 目标

将现有 Sallen-Key 实验替换为标准反相多重反馈（MFB）二阶低通。电路图、传递函数、状态方程、参数面板、实验名称和大厅封面必须描述同一个物理模型。

## 拓扑

- 运放同相端直接接地。
- 输入通过 `R1` 到达节点 `v1`。
- `R2` 将 `v1` 接到反相端。
- `R3` 从输出反馈到 `v1`。
- `C1` 从 `v1` 接地。
- `C2` 从输出反馈到反相端。
- 输出端保留电压读数，不再绘制饱和度横条。

该结构是反相 MFB 低通，不再使用 Sallen-Key 名称。运放输出限幅仍属于仿真行为，可由参数面板开关控制，但不在原理图中画成进度条。

## 数学模型

理想运放条件下，传递函数为：

\[
G(s)=\frac{-R_3/R_1}{R_2R_3C_1C_2s^2+C_2(R_2R_3/R_1+R_2+R_3)s+1}
\]

归一化后写为：

\[
G(s)=\frac{-\frac{R_3}{R_1}a_0}{s^2+a_1s+a_0}
\]

其中 `a0`、`a1`、自然频率、阻尼比、Q 值和负直流增益均由五个真实元件参数计算。仿真继续使用二阶常微分方程，并在显示输出通道单独应用可选限幅。

## 组件与迁移

- 新模型模块命名为 `mfbLowPass`，不保留会误导读者的 Sallen-Key API。
- 实验 ID 从 `active-sallen-key` 改为 `active-mfb`。
- 实验组件和场景组件同步改名为 `MfbLowPassLab`、`MfbLowPassScene`。
- 大厅封面使用反相输入、同相接地和两条反馈支路的静态缩略结构。
- 旧设计文档作为历史记录保留；本设计文档记录当前替代关系。

## 验证标准

- 模型测试验证负直流增益和手算二阶系数。
- 几何测试验证同相端接地、信号进入反相端、两条反馈支路返回正确节点。
- 全仓库不再存在运行时代码中的 `Sallen-Key` 或 `active-sallen-key`。
- 浏览器检查确认原理图无悬空端点、无饱和横条、无多余动态线条。
