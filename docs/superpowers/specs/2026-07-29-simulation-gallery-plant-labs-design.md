# 仿真实验大厅与被控对象实验设计

## 1. 目标

把现有“进入动力学仿真即打开倒立摆”的单实验入口，重构为可扩展的仿真实验大厅。大厅明确分为两类：

1. **被控对象类**：研究结构、参数、输入与输出之间的关系，不提供控制器接口。
2. **验证算法类**：允许修改对象参数、施加输入与扰动，并接入控制器验证算法。现阶段只收纳已有的小车倒立摆。

本阶段实现大厅，以及三个被控对象主题：多质量弹簧—阻尼系统、直流电机、电路系统。电路系统包含无源 RLC 与有源 Sallen-Key 两个场景。

## 2. 非目标

- 不实现平衡车、四轴无人机。
- 不新增 PID、LQR、MPC、模糊控制或神经网络控制接口。
- 不实现任意机械拓扑编辑器或任意电路连线编辑器。
- 不模拟运放内部晶体管、偏置网络和高频寄生参数。
- 不把页面做成机械 CAD 或电子设计自动化软件。

## 3. 信息架构

动力学仿真入口首先展示实验大厅：

```text
仿真实验大厅
├─ 被控对象
│  ├─ 多质量弹簧—阻尼系统
│  ├─ 直流电机
│  ├─ 无源 RLC 电路
│  └─ 有源 Sallen-Key 电路
└─ 验证算法
   └─ 小车倒立摆
```

大厅卡片显示实验名称、类型、核心状态量和简洁动画缩略图。只展示已经可以进入的实验，不用大量“即将推出”卡片占位。

进入实验后，顶部模块导航保持现有四大模块名称。实验内部提供“返回实验大厅”，不同实验之间不通过主模块导航互相冒充。

## 4. 被控对象实验的统一边界

被控对象实验统一遵循以下数据流：

```text
预设结构 → 参数 → 输入或初始条件 → 数值积分 → 动画与单变量输出
```

每个实验由独立定义提供：

- 可用预设结构；
- 参数及合法范围；
- 初始状态；
- 输入信号定义；
- 状态导数计算；
- 可选输出量；
- 动画所需的场景数据；
- 当前模型的方程、传递函数或状态空间说明。

该定义不包含控制器、参考跟踪、闭环开关和控制性能指标。验证算法类继续使用自己的完整接口，不强行与被控对象实验共用控制器协议。

公共实验外壳只负责布局、播放/暂停/复位、仿真时钟、输入编辑、输出选择、图表和错误提示。物理计算与动画组件相互独立，新增对象时不复制整页逻辑。

## 5. 统一交互布局

- **主画面**：对象动画或电路状态动画。
- **结构与参数**：选择预设结构，在合法插槽中增删或启用元件，修改参数。
- **输入**：手动滑杆、恒值、阶跃、正弦和脉冲；仅显示当前实验适用的输入。
- **输出**：一次选择一个主要变量绘图，避免多状态量堆叠。允许用一条弱化的输入曲线作为参照。
- **模型**：紧凑展示当前结构生成的微分方程、传递函数或状态空间，不占用首屏大面积。
- **分析摘要**：只显示对当前对象有意义的极点、稳定性、固有频率、阻尼或稳态增益。

任何结构或参数改变都会重建模型并复位仿真，避免旧状态与新模型混用。数值无效、结构退化或积分发散时暂停仿真并给出具体原因，不伪造输出。

## 6. 多质量弹簧—阻尼系统

### 6.1 结构

- 提供单质量、双质量和三质量串联预设。
- 质量块之间以及端点与固定墙之间提供合法连接槽。
- 每个槽可以启用弹簧、阻尼器或二者并联。
- 元件只能在预设槽中增删，不支持任意拖线。

系统根据当前连接生成质量矩阵、阻尼矩阵和刚度矩阵：

\[
M\ddot{x}+C\dot{x}+Kx=Fu
\]

### 6.2 参数和输入

- 每个质量块：质量、初始位移、初始速度。
- 每个弹簧：刚度。
- 每个阻尼器：阻尼系数。
- 输入作用到选定质量块，支持手动力滑杆、恒力、阶跃、正弦和脉冲力。

### 6.3 输出与动画

输出选择包括任一质量块的位移、速度、加速度，以及任一连接槽的弹簧力或阻尼力。主图一次显示一个选择量。

动画显示质量块位置、弹簧伸缩和阻尼器相对运动。为保证可读性，动画位移采用有上限的视觉缩放，数值图仍使用真实物理量。

## 7. 直流电机

### 7.1 模型

采用电枢控制直流电机的电气—机械耦合模型：

\[
L\dot{i}+Ri+K_e\omega=u,\qquad
J\dot{\omega}+b\omega=K_ti-T_L
\]

状态为电枢电流、角速度和转角。

### 7.2 参数和输入

- 电枢电阻、电感；
- 反电动势常数、转矩常数；
- 转动惯量、黏性摩擦；
- 初始电流、转速和角度；
- 输入电压；
- 可选负载转矩扰动。

电压支持手动滑杆、恒值、阶跃、正弦和脉冲。负载转矩采用独立的恒值、阶跃或脉冲设置。

### 7.3 输出与动画

输出选择包括电流、转速、角度、电磁转矩和机械功率。动画显示电机转子、轴和负载的转动，旁边用简洁仪表表现电流与转速，不模拟内部电磁场。

## 8. 无源 RLC 电路

### 8.1 结构

提供串联 RLC 和并联 RLC 两类预设。元件在预设支路或插槽中增删、启用并修改数值，不支持任意节点连线。

同一串联支路内交换元件绘图位置不会改变理想集中参数模型，界面应明确提示这一点；增删元件或改变串并联关系才改变模型。

### 8.2 激励

- 零输入响应：设置电容初始电压和电感初始电流。
- 零状态或全响应：电压源或电流源支持恒值、阶跃、正弦和脉冲。

无源电路不是默认“自激”。没有独立源时，响应来自电感或电容的初始储能。

### 8.3 输出与动画

输出选择包括源电压/电流、任一元件电压、任一支路电流和储能。电流方向通过流动标记表示，电压用节点色阶和数值表示；颜色只辅助理解，图表保留真实数值和单位。

## 9. 有源 Sallen-Key 电路

### 9.1 控制教学定位

使用理想运放配合两个电阻、两个电容构成二阶 Sallen-Key 低通系统。重点是元件参数、反馈增益、极点、阻尼、带宽和时域响应之间的关系，不讲运放内部实现。

首版使用固定拓扑，可修改 \(R_1,R_2,C_1,C_2\) 以及由反馈电阻决定的闭环增益。提供理想输出和可选输出饱和限制，用于展示线性模型的适用边界。

### 9.2 输入和输出

输入支持恒值、阶跃、正弦和脉冲电压。输出选择包括输入电压、中间节点电压、运放输出和饱和前的理想输出。

模型区实时展示二阶传递函数、极点、自然频率、阻尼比、直流增益和必要的 Bode 摘要。动画突出反馈路径、节点电压和输出饱和状态，不展示晶体管级细节。

## 10. 数值与模型生成

- 机械和电机系统由当前参数实时生成状态方程。
- 电路由对应预设的方程生成器建立状态空间或传递函数。
- 线性状态模型优先使用稳定的矩阵步进；包含饱和等非线性时使用固定小步长 RK4。
- 图表采样与内部积分解耦，避免为画图降低积分稳定性。
- 所有计算在浏览器本地完成，本阶段不需要云服务器。

## 11. 可扩展性

目录按实验拆分物理内核、动画和定义：

```text
lib/simulation/plants/
components/simulations/gallery/
components/simulations/plants/
```

大厅从唯一实验注册表读取卡片元数据，不在组件内部散落实验名称和条件分支。新增被控对象只需注册实验定义、模型和动画，不修改大厅或公共实验外壳。小车倒立摆作为验证算法实验保留其现有独立逻辑，仅接入统一大厅入口。

模块边界必须满足以下约束：

- **实验注册表**只保存标识、名称、类别、简介、缩略图信息和入口组件，不承担物理计算。
- **对象定义**声明参数、输入、输出和默认结构，不引用 React 组件。
- **数值内核**使用纯函数接收模型、状态、输入与步长并返回新状态，可以脱离页面独立测试。
- **动画组件**只读取标准化场景状态，不自行积分，也不反向修改模型参数。
- **公共实验外壳**只处理布局、时钟、播放状态、图表和选择器，不包含“如果是电机”“如果是弹簧”等对象专属判断。
- **模型说明组件**消费对象内核提供的结构化公式和分析摘要，不在 JSX 中重新推导物理模型。
- **输入信号模块**复用恒值、阶跃、正弦、脉冲和手动输入定义；对象只声明自己允许哪些类型。
- **输出通道模块**通过统一元数据提供名称、单位和取值函数，新增状态量不需要修改图表组件。

机械拓扑生成、电机模型、无源电路模型和有源电路模型分别位于独立目录，彼此不能直接引用内部实现。公共矩阵、积分和信号工具下沉到基础层，避免复制。

扩展性验收采用一个最小虚拟实验：只注册对象定义、纯计算函数和动画占位组件，不修改大厅与公共外壳源码，即可自动出现在正确分类并完成输入、输出和复位流程。若做不到，则视为架构未达标。

## 12. 测试与验收

### 12.1 数值测试

- 单质量弹簧系统与解析固有频率一致；无阻尼时机械能近似守恒。
- 多质量系统矩阵维度和连接关系随元件启用状态正确变化。
- 直流电机稳态电流、转速和转矩满足代数平衡关系。
- 串联、并联 RLC 的特征值和标准模型一致。
- Sallen-Key 参数生成的直流增益、自然频率和阻尼正确。
- 输出选择只改变展示通道，不改变底层仿真状态。
- 最小虚拟实验可以只通过注册进入大厅并运行，证明公共外壳没有对象专属分支。

### 12.2 界面验收

- 大厅清楚分成“被控对象”和“验证算法”。
- 四个被控对象场景和倒立摆均可无缝进入与返回。
- 参数改变后模型、动画、摘要和输出同步更新。
- 每个实验主图只显示一个选定输出量。
- 被控对象页面没有控制器开关或算法配置。
- 数值输入不出现浏览器原生步进按钮，页面无横向白条或样式失配。
- 桌面宽屏和常见窄屏下信息仍可读。

## 13. 交付顺序

1. 建立实验目录、公共类型和仿真实验大厅。
2. 接入现有倒立摆卡片和返回大厅流程。
3. 实现弹簧—阻尼实验。
4. 实现直流电机实验。
5. 实现无源 RLC 与有源 Sallen-Key 实验。
6. 完成统一 UI、数值测试、浏览器交互检查和回归测试。
