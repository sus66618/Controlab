# 系统辨识模块设计

## 定位

系统辨识是首页第三个独立主模块，与系统分析、现代控制、动力学仿真并列。首版聚焦“从时序数据得到可验证模型”，不混入控制器设计。

## 数据与模型

支持三种数据入口：内置示例、粘贴 CSV、加载另一内置实验。CSV 接受 `t,u,y` 三列，可含表头；无效行被忽略，少于必要样本时给出错误。

首版采用离散 ARX 模型：

`y(k) + a1 y(k-1) + ... + ana y(k-na) = b1 u(k-nk) + ... + bnb u(k-nk-nb+1)`

用户可调输出阶次 na、输入阶次 nb 和纯延迟 nk。参数由最小二乘计算，并使用同一输入进行自由仿真验证，而不是只展示一步预测结果。

## 页面结构

- 左侧：数据来源、CSV 输入、模型阶次和辨识按钮。
- 右侧主画布：数据预览、拟合对比、残差三种视图。
- 下方紧凑结论栏：拟合度、RMSE、样本数、辨识方程与参数。

默认展示带噪二阶对象，使用户进入页面即可看到“测量曲线与辨识曲线”的差异。

## 架构

- `lib/systemIdentification.ts`：CSV 解析、最小二乘、ARX 拟合、自由仿真和指标。
- `components/identification/SystemIdentificationLab.tsx`：独立页面。
- `ControlLab.tsx` 与 `Cover.tsx`：加入独立导航入口，并把首页闭环控制卡片替换为现代控制。

## 首页四模块

1. 系统分析：传递函数、时频域、根轨迹、奈氏图以及经典闭环控制。
2. 现代控制：状态空间、状态反馈、观测器与卡尔曼滤波。
3. 系统辨识：数据、ARX 模型和验证。
4. 动力学仿真：倒立摆及后续物理场景。

## 验证

数值测试覆盖 CSV 解析、已知 ARX 参数恢复、自由仿真和拟合指标；构建测试覆盖新页面导航。
