# 现代控制完整链条设计

## 定位

现代控制作为首页独立主模块，在现有状态空间工作台内扩展，不另建一套模型输入。用户编辑的 A、B、C、D、初始状态和输入信号同时服务于分析、反馈设计与状态估计。

## 工作流

页面内部提供两个一级视图：

1. 状态空间：保留矩阵编辑、响应、轨迹、特征值、能控能观与稳定性。
2. 反馈与估计：按“状态反馈 → 状态估计 → 输出反馈验证”组织。

状态反馈支持手动 K、SISO 极点配置和 LQR。极点配置只在单输入且完全能控时启用；LQR 使用可编辑的 Q 对角元素与 R 对角元素。

状态估计支持全状态直接反馈、Luenberger 观测器极点配置和稳态卡尔曼滤波。观测器极点配置只在单输出且完全能观时启用；卡尔曼滤波使用过程噪声 Qn 与测量噪声 Rn。

输出反馈统一采用 `u = u_ext - K x_hat`，并显示真实状态、估计状态、估计误差、控制输入以及闭环/观测器极点。

## 交互与边界

- 所有计算随参数变化即时更新，不设置多余的“应用”按钮。
- 不满足能控、能观或 SISO 条件时，明确给出原因并回退到手动增益，不伪造结果。
- 图像仍使用现有 Plot 组件，外部图例避免遮挡。
- 默认示例必须在 LQR 与卡尔曼配置下数值稳定。

## 架构

- `lib/modernControl.ts`：极点配置、LQR、卡尔曼、输出反馈仿真，完全独立于 React。
- `components/modern-control/ModernControlDesigner.tsx`：参数编辑与结果可视化。
- `StateSpaceLab.tsx`：共享模型并切换“状态空间 / 反馈与估计”。

## 验证

使用数值测试验证极点配置、LQR 稳定化、观测器误差收敛和卡尔曼增益维度；整站构建验证组件集成。
